# Guesty Integration — Knowledge Review History

This file is the chronological audit trail for reviews of the repository's
durable knowledge. It is intentionally separate from
[`KNOWLEDGE.md`](KNOWLEDGE.md), which contains the current validated technical
contract. A result recorded here describes what was concluded at that time; it
must not override a current knowledge entry. When later evidence invalidates a
historical result, mark that row as superseded and link the replacement
knowledge ID.

Never place credentials, tokens, PINs, bearer links, guest data, private URLs,
or real reservation/listing identifiers in this history.
